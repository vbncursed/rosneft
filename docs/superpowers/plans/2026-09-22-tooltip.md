> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shared `Tooltip` (Popover API, own placement) and every icon-only control in the SPA wired to it, replacing native `title` hints.

**Architecture:** `shared/ui/tooltip` = a pure placement function, a hook that owns timing (500 ms delay, 300 ms shared warm-up, keyboard-only focus, Esc, press, touch), and a component that clones its one child with those handlers and renders a `popover="manual"` element in the top layer while open. Shared components adopt it once; plain icon-only buttons are wrapped at their call sites.

**Tech Stack:** React 19, TypeScript, Tailwind 4, Vitest (fake timers) + Testing Library, Cosmos, yarn.

**Spec:** `docs/superpowers/specs/2026-09-22-tooltip-design.md` — decisions T1–T10 and the Integration tables are authoritative.

```ts
export type Side = "top" | "bottom";
export type Box = { top: number; left: number; width: number; height: number };

/** Space between the trigger and the tooltip. */
export const GAP = 6;
/** The tooltip never comes closer than this to the viewport's edge. */
export const EDGE = 8;

// Above or below the trigger, centred on it. It takes the other side when the
// asked one does not fit and the other one does; with room on neither it keeps
// the asked side rather than jump. Horizontally it slides to stay on screen.
export function placeTooltip(
  trigger: Box,
  tip: { width: number; height: number },
  viewport: { width: number; height: number },
  side: Side,
): { top: number; left: number; side: Side } {
  const above = trigger.top - GAP - tip.height;
  const below = trigger.top + trigger.height + GAP;
  const fitsAbove = above >= EDGE;
  const fitsBelow = below + tip.height <= viewport.height - EDGE;
  const chosen: Side =
    side === "top" ? (fitsAbove || !fitsBelow ? "top" : "bottom") : fitsBelow || !fitsAbove ? "bottom" : "top";
  const centred = trigger.left + trigger.width / 2 - tip.width / 2;
  const left = Math.min(Math.max(centred, EDGE), viewport.width - EDGE - tip.width);
  return { top: chosen === "top" ? above : below, left, side: chosen };
}
```

Behaviour (spec T3–T10) — the hook owns it:
- `pointerenter` with `pointerType === "mouse"` → open after 500 ms, **or immediately** (with `instant = true`, no enter animation) if another tooltip closed less than 300 ms ago (module-level `lastClosedAt`).
- `pointerleave` / `blur` → cancel the timer, close, stamp `lastClosedAt = Date.now()` if it was open.
- `pointerdown` → close and mark `pressedByPointer` so the focus that follows does not open it; `blur` clears the mark.
- `focus` without `pressedByPointer` → open immediately.
- While open, a `keydown` listener on `window` (capture): `Escape` → close and `stopPropagation()` so a modal's own Esc handler below does not also fire.
- Non-mouse pointers never open.

`use-tooltip.ts`:

```ts
import { useCallback, useEffect, useRef, useState } from "react";

export const OPEN_DELAY = 500;
export const WARM_WINDOW = 300;

// One clock for every tooltip on the page: the pointer that just left one
// tooltip's trigger is reading along a row, so the next one opens at once.
let lastClosedAt = Number.NEGATIVE_INFINITY;

/** Tests start cold: the clock is module state and would leak between them. */
export function resetTooltipWarmup() {
  lastClosedAt = Number.NEGATIVE_INFINITY;
}

export function useTooltip() {
  const [state, setState] = useState<{ open: boolean; instant: boolean }>({ open: false, instant: false });
  const timer = useRef<ReturnType<typeof setTimeout> | undefined>(undefined);
  const pressed = useRef(false);

  const close = useCallback(() => {
    clearTimeout(timer.current);
    setState((s) => {
      if (s.open) lastClosedAt = Date.now();
      return { open: false, instant: false };
    });
  }, []);

  useEffect(() => () => clearTimeout(timer.current), []);

  useEffect(() => {
    if (!state.open) return;
    const onKey = (event: KeyboardEvent) => {
      if (event.key !== "Escape") return;
      event.stopPropagation();
      close();
    };
    window.addEventListener("keydown", onKey, true);
    return () => window.removeEventListener("keydown", onKey, true);
  }, [state.open, close]);

  const triggerProps = {
    onPointerEnter(event: React.PointerEvent) {
      if (event.pointerType !== "mouse") return;
      if (Date.now() - lastClosedAt < WARM_WINDOW) {
        setState({ open: true, instant: true });
        return;
      }
      clearTimeout(timer.current);
      timer.current = setTimeout(() => setState({ open: true, instant: false }), OPEN_DELAY);
    },
    onPointerLeave: close,
    onPointerDown() {
      pressed.current = true;
      close();
    },
    onFocus() {
      if (!pressed.current) setState({ open: true, instant: false });
    },
    onBlur() {
      pressed.current = false;
      close();
    },
  };

  return { ...state, triggerProps };
}
```

(`Date.now()` because Vitest's fake timers fake `Date` by default, so `advanceTimersByTime` moves the warm-up clock too. Import `PointerEvent` as a type from `react` rather than using the `React.` namespace if that is the file style.)

`tooltip.tsx`:

```tsx
import { cloneElement, useId, useLayoutEffect, useRef, useState, type CSSProperties, type ReactElement } from "react";
import { clsx as cx } from "clsx";
import { placeTooltip, type Side } from "./tooltip-geometry";
import { useTooltip } from "./use-tooltip";

export type TooltipProps = { label: string; shortcut?: string; side?: Side; children: ReactElement };

type ChildProps = Record<string, unknown> & { disabled?: boolean };

/**
 * Names an icon-only control on hover (after a beat) and on keyboard focus.
 * It lives in the popover top layer, so no `overflow-hidden` panel, stacking
 * context or canvas can clip it. A disabled child gets a wrapper to hover,
 * because a disabled button receives no pointer events.
 */
export function Tooltip({ label, shortcut, side = "top", children }: TooltipProps) {
  const { open, instant, triggerProps } = useTooltip();
  const id = useId();
  const anchor = useRef<HTMLElement | null>(null);
  const tip = useRef<HTMLDivElement>(null);
  const [place, setPlace] = useState<{ top: number; left: number; side: Side } | null>(null);

  useLayoutEffect(() => {
    if (!open || !tip.current || !anchor.current) return;
    tip.current.showPopover?.();
    const r = anchor.current.getBoundingClientRect();
    const t = tip.current.getBoundingClientRect();
    setPlace(placeTooltip(r, t, { width: window.innerWidth, height: window.innerHeight }, side));
  }, [open, side]);

  const child = children as ReactElement<ChildProps>;
  const merge = (name: keyof typeof triggerProps) => (event: never) => {
    (child.props[name] as ((e: never) => void) | undefined)?.(event);
    (triggerProps[name] as (e: never) => void)(event);
  };
  const handlers = Object.fromEntries(
    (Object.keys(triggerProps) as (keyof typeof triggerProps)[]).map((k) => [k, merge(k)]),
  );
  const described = open ? { "aria-describedby": id } : {};

  const trigger = child.props.disabled ? (
    <span ref={(el) => void (anchor.current = el)} className="inline-flex" {...handlers}>
      {cloneElement(child, described)}
    </span>
  ) : (
    cloneElement(child, {
      ...handlers,
      ...described,
      ref: (el: HTMLElement | null) => void (anchor.current = el),
    })
  );

  const style: CSSProperties = place ? { top: place.top, left: place.left } : { visibility: "hidden" };

  return (
    <>
      {trigger}
      {open ? (
        <div
          ref={tip}
          id={id}
          role="tooltip"
          popover="manual"
          style={style}
          className={cx(
            "pointer-events-none fixed m-0 inline-flex items-center gap-2 rounded-[6px] border border-line-2 bg-panel-2 px-2 py-1 text-[11px] text-fg shadow-elevation",
            !instant &&
              "transition-[opacity,translate] duration-120 ease-out starting:opacity-0 motion-reduce:starting:translate-y-0",
            !instant && (place?.side === "bottom" ? "starting:-translate-y-0.5" : "starting:translate-y-0.5"),
          )}
        >
          {label}
          {shortcut ? (
            <kbd className="rounded-[4px] border border-line-2 px-[5px] font-mono text-[10px] text-muted">{shortcut}</kbd>
          ) : null}
        </div>
      ) : null}
    </>
  );
}
```

Notes the implementer must honour: if the child already has a `ref` (React 19 passes `ref` as a prop), compose it with the anchor ref instead of overwriting it (`child.props.ref`). `popover="manual"` elements default to `inset: 0; margin: auto` in the UA sheet — the `fixed m-0` classes plus explicit `top/left` must win; verify in the browser. jsdom lacks `showPopover` — hence `?.()`. Keep each file ≤ 200 lines; split the handler merge into a helper if needed.
