# Site icon 2e — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the old green cube mark with icon **2e "Placed on ground"** from the Claude Design file `Site Icon.dc.html` everywhere an icon ships: the browser tab, the PWA manifest, iOS home screen, and the Tauri desktop bundle (macOS, Windows, Linux).

**Architecture:** Three source SVGs copied from the mock's symbols live in `frontend/icons/`. A single script, `frontend/icons/render.py`, rasterises them with headless Chromium (Python Playwright, `omit_background`) and packs `.ico` with Pillow and `.icns` with `iconutil`. Its outputs are committed to `frontend/public/` and `desktop/src-tauri/icons/`, and one command regenerates all of them.

**Tech Stack:** SVG, Python 3 + Playwright (Chromium) + Pillow, macOS `iconutil`.

**Spec:** a bounded task, approved in chat on 2026-09-24 and restated under "Design" below. The mock is in project `b5fa4afe-073c-4f90-8239-acaff290c342`, file `Site Icon.dc.html`, block `#2e`, symbols `g-1e`, `g-1e-m`, `g-1e-s`.

## Design: which cut goes where

| Output | Source | Shape |
|---|---|---|
| `public/favicon.svg` | small | ground rect `rx="6"`, the mock's 3 px corner at 16 |
| `public/favicon.ico` | 16 from small; 32 and 48 from main | same rx ratio (6/32), transparent corners |
| `public/apple-touch-icon.png` 180 | main | full-bleed opaque square (iOS masks it) |
| `public/icon-192.png`, `icon-512.png` (`any`) | main | full-bleed opaque square |
| `public/icon-maskable-512.png` | maskable | full-bleed opaque square |
| `desktop/.../32x32.png`, `128x128.png`, `128x128@2x.png` (256), `icon.png` (512) | main | full-bleed opaque square (Linux, window icon) |
| `desktop/.../icon.ico` 16, 24, 32, 48, 64, 128, 256 | 16 from small; the rest from main | corner ratio 4/24 (the mock's Windows taskbar tile), transparent corners |
| `desktop/.../icon.icns` | main | macOS superellipse mask (n = 5), 824 px of artwork on a 1024 canvas, transparent margins (Apple grid, same as today) |

The Windows `.ico` gains rounded corners. This reverses the current `desktop/README.md` rule ("Windows and Linux take the square PNG and `.ico` unmasked"), because the mock now draws the taskbar tile at 4 px / 24. Linux PNGs stay square.

```python
"""Render icon 2e (Site Icon.dc.html) into every format the web app and the
desktop bundle ship. Run from anywhere:  python3 frontend/icons/render.py
Needs Python Playwright (Chromium), Pillow, and macOS iconutil for .icns."""
import math, re, shutil, subprocess, tempfile
from io import BytesIO
from pathlib import Path
from PIL import Image, ImageDraw
from playwright.sync_api import sync_playwright

HERE = Path(__file__).resolve().parent
PUBLIC = HERE.parent / "public"
DESKTOP = HERE.parents[1] / "desktop" / "src-tauri" / "icons"
SRC = {k: (HERE / f).read_text() for k, f in
       {"main": "icon.svg", "maskable": "icon-maskable.svg", "small": "icon-small.svg"}.items()}


def rounded(svg: str, rx: float) -> str:
    """The ground rect with corners, so the tile's corners turn transparent."""
    return svg.replace('<rect width="32" height="32"', f'<rect width="32" height="32" rx="{rx}"', 1)


def render(page, svg: str, px: int) -> Image.Image:
    page.set_viewport_size({"width": px, "height": px})
    page.set_content(
        f'<html><body style="margin:0;background:transparent">'
        f'{svg.replace("<svg ", f"<svg width=\"{px}\" height=\"{px}\" ", 1)}</body></html>'
    )
    return Image.open(BytesIO(page.screenshot(omit_background=True))).convert("RGBA")


def superellipse(size: int, n: float = 5.0, ss: int = 4) -> Image.Image:
    big, pts = size * ss, []
    r = big / 2.0
    for i in range(2048):
        t = 2 * math.pi * i / 2048
        ct, st = math.cos(t), math.sin(t)
        pts.append((r + math.copysign(abs(ct) ** (2 / n), ct) * r,
                    r + math.copysign(abs(st) ** (2 / n), st) * r))
    m = Image.new("L", (big, big), 0)
    ImageDraw.Draw(m).polygon(pts, fill=255)
    return m.resize((size, size), Image.LANCZOS)


def main() -> None:
    fav = rounded(SRC["small"], 6)          # 3 px at 16, as the mock's tab
    win = 32 * 4 / 24                        # 4 px at 24, as the mock's taskbar
    (PUBLIC / "favicon.svg").write_text(fav)
    with sync_playwright() as p:
        page = p.chromium.launch().new_page(device_scale_factor=1)
        png = lambda key, px, rx=None: render(page, rounded(SRC[key], rx) if rx else SRC[key], px)

        # Web: favicon.ico (16 small, 32/48 main, rounded), PWA and iOS squares.
        ico = [png("small", 16, 6), png("main", 32, 6), png("main", 48, 6)]
        ico[0].save(PUBLIC / "favicon.ico", sizes=[(16, 16), (32, 32), (48, 48)], append_images=ico[1:])
        png("main", 180).save(PUBLIC / "apple-touch-icon.png")
        png("main", 192).save(PUBLIC / "icon-192.png")
        png("main", 512).save(PUBLIC / "icon-512.png")
        png("maskable", 512).save(PUBLIC / "icon-maskable-512.png")

        # Desktop: square PNGs (Linux, window icon), rounded .ico (Windows).
        for name, px in [("32x32.png", 32), ("128x128.png", 128), ("128x128@2x.png", 256), ("icon.png", 512)]:
            png("main", px).save(DESKTOP / name)
        sizes = [16, 24, 32, 48, 64, 128, 256]
        frames = [png("small" if s == 16 else "main", s, win) for s in sizes]
        frames[-1].save(DESKTOP / "icon.ico", sizes=[(s, s) for s in sizes], append_images=frames[:-1])

        # macOS: superellipse, 824 of artwork on a 1024 canvas (Apple grid).
        body = png("main", 824)
        body.putalpha(superellipse(824))
        master = Image.new("RGBA", (1024, 1024), (0, 0, 0, 0))
        master.paste(body, (100, 100), body)
        with tempfile.TemporaryDirectory() as tmp:
            iconset = Path(tmp) / "icon.iconset"
            iconset.mkdir()
            for s in (16, 32, 128, 256, 512):
                master.resize((s, s), Image.LANCZOS).save(iconset / f"icon_{s}x{s}.png")
                master.resize((s * 2, s * 2), Image.LANCZOS).save(iconset / f"icon_{s}x{s}@2x.png")
            subprocess.run(["iconutil", "-c", "icns", str(iconset), "-o", str(DESKTOP / "icon.icns")], check=True)


if __name__ == "__main__":
    main()
```
